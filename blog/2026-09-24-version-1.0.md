# Bienvenidos al Nuevo Sistema Web

El día de hoy se ha liberado la versión 1.0 del sistema de gestión clínica para el área de Psicología del CAP. 

**Novedades:**
* Módulo de citas integrado.
* Expedientes digitales encriptados.
* Manual de usuario interactivo agregado al botón de ayuda.

Si encuentran algún error, por favor repórtenlo al área de sistemas.
