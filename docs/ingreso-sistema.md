# Acceso y Seguridad

Procedimientos para acceder a la plataforma y descripción de los niveles de autorización.

## Ingreso a la Plataforma

1. Ejecute un navegador web compatible (Google Chrome, Microsoft Edge o Mozilla Firefox).
2. Navegue a la URL oficial del sistema (proporcionada por el administrador).
3. En la interfaz de autenticación, ingrese las credenciales asignadas:
   * **Usuario:** Correo electrónico institucional.
   * **Contraseña:** Clave de acceso personal.
4. Presione el botón **Ingresar**.

:::info Restablecimiento de Credenciales
Si el acceso es denegado por contraseña incorrecta, utilice la opción "Olvidé mi contraseña" en la pantalla de inicio para generar un enlace de recuperación vía correo electrónico.
:::

## Roles y Permisos

El sistema restringe las funciones según el rol asignado a cada usuario para mantener la confidencialidad de los datos:

* **Terapeuta (Psicología):** Acceso completo a su agenda personal, lectura y escritura de notas de evolución, y visualización de historiales clínicos completos.
* **Recepción / Administración:** Autorización para agendar, modificar o cancelar citas, y crear perfiles de pacientes nuevos. Restricción total de lectura sobre el contenido de los expedientes clínicos.
* **Administrador del Sistema:** Capacidad para gestionar cuentas de usuario, asignar roles y configurar parámetros globales del sistema.
