# Sistema de Gestión Clínica - Psicología

Este portal contiene la documentación operativa del sistema web implementado en el Centro de Atención Permanente (CAP) de Quetzaltenango, sección de Psicología. Su objetivo es estandarizar los procesos de uso de la plataforma para asegurar la integridad de la información clínica y la eficiencia en la atención.

## Estructura de la Documentación

La guía está segmentada según los módulos funcionales del sistema:

* **[Acceso y Seguridad](./ingreso-sistema.md):** Protocolos de inicio de sesión, recuperación de credenciales y definición de roles operativos.
* **[Gestión de Agenda](./gestion-citas.md):** Procedimientos para la programación, modificación y cancelación de consultas psicológicas.
* **[Expedientes Clínicos](./expedientes.md):** Lineamientos para el registro de historiales, ingreso de notas de evolución y consulta de antecedentes.

---

:::tip Búsqueda de Procesos
Utilice la barra de búsqueda superior para localizar instrucciones específicas (ej. "registro de paciente nuevo", "cancelar cita").
:::

:::caution Normativa de Uso
La información manejada en el sistema web principal es de carácter confidencial. El cumplimiento de las guías descritas en este manual es obligatorio para garantizar el resguardo de los datos del paciente según los protocolos del CAP.
:::
